Subject: Biology
Exam style: NSEB (ecology: population estimation by mark-recapture, Lincoln-Petersen index)
Concept tested: N = M x C / R, where M must be the number of marked animals that are still recognisable; correcting for lost marks in the right direction
Hook line (top of slide, <=8 words): Some tags fell off. Now count again.
Question:
Ecologists catch 60 frogs in a pond, tag them and release them. Before the second catch, 1/4 of the tagged frogs lose their tags (no frog dies or leaves). In the second catch, 50 frogs are caught, of which 10 still carry tags. What is the best estimate of the pond's frog population?
Options (A-D, or "integer answer"):
A) 300
B) 225
C) 400
D) 375
Answer: B) 225
Solution (3-6 short lines, for next day's post/caption):
1. Lincoln-Petersen: N = M x C / R (M = marked in the population, C = second catch, R = marked in second catch).
2. Only tagged frogs can be recognised. 1/4 lost tags, so tagged frogs left = 60 x 3/4 = 45.
3. N = 45 x 50 / 10 = 225.
4. The frogs that lost tags are still in the pond, but now they count as "unmarked", so M must be 45, not 60.
Why it's tricky (common trap): Ignoring tag loss gives 300 (A). Many students "correct" in the wrong direction and divide by 3/4, giving 400 (C), or add 25% to get 375 (D). Lost tags make marked animals look rarer, so ignoring the loss OVER-estimates the population. The fix lowers the estimate.
